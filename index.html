Height step and pivot

Height step

Lifts every link above the one before, so the chain climbs like a ladder. Leave it at 0 for a flat chain.

Pivot

Size along the chain

Make links bigger or smaller along the chain. Pick a pattern, then tweak its numbers in the code if you like — the chain re-spaces itself so the joints still meet.

How the code works

JavaScript f(n_it, n_it_nor) → scale. n_it is the link number (0, 1, 2 …), n_it_nor the same counted from 0 (first link) to 1 (last link). Return one number to scale the whole link, or {x, y, z} to scale each direction separately — e.g. taller without getting wider. 1 = original size.

Colour along the chain

Give the links different colours. Colours are saved in OBJ, GLB and PLY files; STL has no colour.

How the code works

JavaScript f(n_it, n_it_nor, base) → colour. base is the link's own colour {r, g, b} (each 0–1). Return 'invert' to swap the link's colours (white↔green on a 2-colour model), a colour to tint it (0xff0000, '#ff0000', 'tomato' or {r, g, b}), or base to leave it. A tint multiplies a coloured model's own colours; on a plain part it sets the colour outright.

Custom path (code)

Any curve you like, as JavaScript: return the point {x, y, z} in mm for a position t along the curve. The Shape, Start radius and Loop spacing controls above rewrite this code.

How the code works

f(t, n_it, n_it_nor, z_stack) → {x, y, z}. t grows continuously along the curve (not one per link). n_it is the number (0 … count-1) of the link being placed, n_it_nor the same from 0 to 1 — use these for anything that should step per link, e.g. z: n_it * 3 for a staircase. z only lifts a link, it never tilts it. z_stack is the height already added by the height step (Joints page) before this link; it is applied automatically on top of your z, so read it if you need it but don't return it.
